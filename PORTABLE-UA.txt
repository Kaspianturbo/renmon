Renmon — portable, без інсталятора

macOS: відкрийте Renmon.app.
Windows: відкрийте Renmon.exe.
Зберігайте всю папку разом: застосунок, profiles та, на Windows, _internal.
Розпакуйте архів перед запуском у папку, доступну для запису, наприклад Документи/Renmon.
Python і залежності включені в готову збірку; HTTP-сервера немає, браузер не потрібний.
Профіль profiles/11075.json та журнал logs розташовані поруч із застосунком.
Закриття вікна зупиняє опитування й автопідключення та звільняє ELM. Завершення поточного запиту може зайняти кілька секунд.

Windows потребує Microsoft Edge WebView2 Evergreen Runtime. Якщо він відсутній,
з'явиться стандартне вікно Windows з посиланням на завантаження. Кнопка «Так»
відкриє офіційний сайт; нічого автоматично не встановлюється.
https://developer.microsoft.com/microsoft-edge/webview2/#download-section

Спаруйте V-LINK через Bluetooth системи (PIN 1234), виберіть його порт у Renmon.
Windows: вихідний COM-порт (Bluetooth Classic SPP). macOS: /dev/cu.V-LINK.
Перед читанням програма перевіряє відповідність профілю ECU через 2180. Команди запису заблоковані.
Демонстрація працює без адаптера. База Pyren/DDT для запуску не потрібна.

Збірка macOS не має Developer ID/notarization. macOS може попросити підтвердити
відкриття через Системні параметри → Конфіденційність і безпека → Відкрити попри це.
Не відключайте захист системи глобально. Переміщуйте всю папку разом, не лише .app.

Для розробника: збирайте окремо на кожній ОС. На Windows запустіть Build-Windows.cmd
у вихідному коді (потрібні Python 3.10+, Node.js та інтернет лише для збірки).
На macOS: python -m pip install '.[desktop,build]', потім npm ci і python packaging/build_portable.py.
Готові файли з'являться у dist. Це не інсталятор.

Автопідключення типово вимкнене. Позначте чекбокс для фонових спроб раз на 3 с.
Без нього порт відкривається лише після «Почати» або «Визначити профіль».
Якщо UI не відповідає понад 15 с, watchdog припиняє читання й автопідключення
та закриває порт. Для відновлення роботи перезапустіть застосунок.
CSV зберігається через системний діалог вибору файла.
