Renmon для Windows — desktop без HTTP-сервера

Готова збірка: відкрийте Renmon.exe, зберігаючи поруч _internal та profiles.
Python і Node.js для готової збірки не потрібні. Потрібен WebView2 Evergreen Runtime:
якщо його немає, Renmon покаже стандартний діалог із посиланням Microsoft.

Запуск вихідного коду: потрібні Python 3.10+ і Node.js. Start-Renmon.cmd підготує залежності
та відкриє окреме вікно PyWebView. Браузер і localhost більше не використовуються.

Спаруйте V-LINK у Bluetooth Windows (PIN 1234). Виберіть його вихідний COM-порт
у Renmon. Потрібен Bluetooth Classic SPP або USB ELM; BLE без COM не підтримується.
Автопідключення типово вимкнене. Без нього відкриття порту відбувається після
«Почати» або «Визначити профіль», без фонових повторів. Інші діагностичні програми
мають звільнити порт. Демонстрація працює без автомобіля.

Закриття вікна завершує опитування й автопідключення та звільняє порт.
Watchdog виконає те саме після понад 15 с без відповіді UI. Поточний запит
може завершуватись до свого timeout. Після втрати UI потрібен перезапуск.
Журнали розташовані в logs; CSV зберігається через системний Save dialog.

Збірка: Build-Windows.cmd; на комп’ютері збирача потрібні Python 3.10+, Node.js
та інтернет. Нативна Windows-збірка виконується на Windows, не на macOS.
Фізичний адаптер і native Windows GUI після змін ще потребують перевірки.
